**Monolith Dashboard** es una plataforma web que analiza tu código de Node.js (Express/Fastify) y genera automáticamente documentación Swagger, tests y un SDK de TypeScript. 

Es la interfaz visual del ecosistema **Monolith-Core**, diseñada para que los desarrolladores ahorren horas de trabajo manual.

## ✨ Características

- ⚡ **Análisis de rutas**: Pega tu código, sube un archivo o conecta con GitHub.
- 🎨 **Editor interactivo**: Resaltado de sintaxis con Monaco Editor (el motor de VS Code).
- 📊 **Generación automática**: Descarga Swagger, Tests y más.
- 🔗 **GitHub Gists**: Exporta tus archivos generados directamente a GitHub.
- 📜 **Historial**: Guarda tus últimos análisis en el navegador.

## 💻 Ejecutar Localmente

1. Clona el repositorio:
```bash
  git clone https://github.com/AiiDev0/monolith-dashboard.git
```
2. Instala las dependencias:
```bash
  npm install
```
3. Inicia el servidor:
```bash
  npm run dev
```
4. Abre `http://localhost:3000` en tu navegador.
